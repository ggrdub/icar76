# I-car76: демонстрационный сайт

Одностраничный макет для техцентра I-car76. Статический сайт без сборки; форма открывает WhatsApp с подготовленным сообщением. Время записи подтверждает мастер. Информация об услугах и контактах взята из карточки 2ГИС; перед использованием необходимо согласовать содержание и фотографии с владельцем. Фотография носит иллюстративный характер.
